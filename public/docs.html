Administrator Control Center

Administrators have full executive control over housing society operations:

  • Resident Management: Add new residents, modify flat allocations, and review pending registrations.
  • Role Management: Grant or revoke Admin rights dynamically under Role & Access Settings.
  • Financial Overview: Track monthly maintenance billing collections and generate audit reports.

Resident Portal Guide

Residents can manage their apartment dues and society amenities:

  • Maintenance Bills: View monthly invoices, simulate online UPI/Card payments, and download PDF receipts.
  • Gate Approvals: Approve or deny visitor entry requests sent by gate security guards in real time.
  • Amenity Booking: Reserve the Clubhouse, Community Hall, or Lawn with double-booking prevention.

Security Gate Control Guide

Security Guards issue digital gate passes for guests, cabs, delivery agents, and maintenance specialists:

  • Check-In Pass: Register visitor name, phone, destination flat, and purpose of visit.
  • Check-Out: Click Check-Out when visitors exit the society gates.

REST API Endpoints Reference

SocietyHub exposes standard REST endpoints for JWT authentication and data management:

POST /api/auth/login - Email/Password Login (JWT token)
POST /api/auth/register - Account Registration
POST /api/auth/google - Google OAuth Integration
GET /api/auth/me - Get Profile Token Info
GET /api/auth/pending - List Pending Registrations (Admin)
POST /api/auth/approve - Approve Pending User Account (Admin)
