Cookie & Local Storage Policy

Last Updated: July 27, 2026

1. Essential Storage

SocietyHub uses browser local storage (`localStorage`) and session storage to maintain authentication tokens, user role profiles, theme preferences (`data-theme`), and offline society database caches.

2. Performance & Analytics

Firebase Analytics is integrated to measure system load performance and user interaction metrics. No sensitive financial or security gate pass details are tracked by third parties.
