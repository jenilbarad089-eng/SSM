The Problem vs Solution

Why Housing Societies Need SocietyHub

Transforming paper-cluttered manual operations into modern digital administration.

Traditional Manual Challenges
  • Paper Billing & Unreconciled Dues: Delayed collections, lost paper receipts, manual bank reconciliation spreadsheets.
  • Unsecure Gate Physical Registers: Visitors write fake phone numbers, no resident verification prior to entry, lost logs.
  • Untracked WhatsApp Complaints: Complaints lost in group chats, zero accountability, unresolved leakages and electrical faults.
  • Missed Notice Announcements: Physical notice boards on lobby pillars go unread during emergencies or AGM meetings.
SocietyHub Cloud Solution
  • Automated Maintenance & Instant Receipts: 1-click payments, live balance tracking, and printable PDF invoices generated instantly.
  • Digital Gate Pass & Security Verification: Security guards log entry with verification codes; residents approve passes in real-time.
  • Ticketed Complaint Redressal Engine: Lifecycle tracking: Pending → In Progress → Resolved, with resolution audit trails.
  • Universal Notification Center & Polls: High-priority alerts sent to resident dashboards; democratic society voting polls.

Full-Stack Frameworks

Modern Full-Stack Technology Stack

High performance, zero framework bloat, offline-first reliability.

Frontend
  • • HTML5 & CSS3: Modern semantic DOM structure with custom CSS variables.
  • • Bootstrap 5.3: Responsive 12-column grid, modals, tabs, and offcanvas.
  • • FontAwesome 6: Consistent iconography across dashboards.
  • • Chart.js: Interactive bar and doughnut financial visual charts.
  • • Google Fonts: Plus Jakarta Sans & Inter typography.
Backend API
  • • Node.js & Express: High-throughput REST API serving endpoints.
  • • bcryptjs: Industrial salt-rounds password hashing.
  • • jsonwebtoken (JWT): Stateless authentication tokens.
  • • CORS & Middleware: Route protection and role verification guards.
  • • Auth Middleware: Server-side token validation on protected APIs.
Data Engine
  • • SystemDB Engine: Resilient offline-first LocalStorage state manager.
  • • seed.json Master: Complete schema for users, flats, billing, and logs.
  • • Version Cache Busting: Auto-updates client state on schema revision.
  • • Firebase SDK: Google OAuth single-sign-on client integration.
  • • CSV Exporter: Client-side dynamic CSV audit log generation.
Cloud & PWA
  • • Vercel Cloud: Edge global CDN hosting with zero-config serverless runtime.
  • • PWA Service Worker: Standalone desktop/mobile installable app.
  • • Offline Caching: Core assets cached for offline operation.
  • • GitHub CI/CD: Automated branch deployment pipelines.
  • • SSL/TLS Enforced: 100% encrypted HTTPS traffic.
